# Internship Projects - Codec Technologies
This repository contains the projects completed during my Web Development Internship.

## 1. Expense Tracker (Vanilla JS)
A lightweight tool to manage daily finances.
* **Tech:** HTML5, CSS3, JavaScript.
* **Features:** Add/Delete expenses, auto-calculation of total balance, and responsive design.

## 2. Real-Time Chat App (Firebase)
A cloud-based messaging application.
* **Tech:** JavaScript, Firebase Firestore.
* **Features:** Instant message delivery and persistent chat history.

## How to Run
1. Clone this repository.
2. Open `index.html` (Tracker) or `chat.html` (Chat) in any web browser.
